# 项目设计与迭代｜Xiang Mu

## 项目定位

Xiang Mu 是一套本地口播视频剪辑工作台，将视频导入、静音分析、片段复核、字幕编辑、画面包装和成片导出整合为一条可操作的流程。

项目从实际口播剪辑中的重复劳动出发，逐步从质量规则演示扩展为能够处理真实视频素材的本地工具。

## 解决的问题

口播视频处理包含多个连续环节：

- 视频中存在停顿、重复录制和需要人工判断的片段。
- 静音分析可以提供剪辑候选，但最终保留范围需要结合原片试听和画面判断。
- 字幕需要校正文本并与剪辑后的时间轴保持一致。
- 重点花字需要单独设置文案、出现时机和画面位置。
- BGM、音效和字幕动画需要真正进入最终视频，而不只是保存为配置参数。

因此，工作台采用「自动分析提供候选 → 人工复核与编辑 → 参数化包装 → 实际渲染导出」的流程。

## 核心设计

### 1. 分析与剪辑决策分开

FFmpeg 检测静音区间并生成候选片段。用户可以逐段试听、修改起止时间、拆分片段和选择保留范围，再确认剪辑方案。

### 2. 统一剪后时间轴

片段经过裁剪后，字幕时间重新映射到成片时间轴。花字和音效也按剪辑后的时间设置，保证包装元素与最终画面同步。

### 3. 包装参数进入真实渲染

字幕和花字通过 ASS / libass 渲染，开头缓推与 BGM/SFX 由 FFmpeg 完成。导出文件是实际生成的 MP4，同时提供 SRT 和 JSON 报告。

### 4. 真实媒体工作台与历史规则演示分离

早期的质量规则演示保留在本地 `/demo`。真实媒体工作台位于首页，负责视频导入、片段编辑和最终导出，两者职责清晰。

## 质量验证

自动化测试围绕实际输出文件进行验证：

- 生成测试视频并执行静音分析与片段裁剪。
- 校验片段时间、说话人类别和编辑输入。
- 检查 SRT 是否正确映射到剪辑后的时间轴。
- 检查最终 MP4 是否包含实际烧录的字幕与花字。
- 检查 BGM/SFX 混音、输出时长和音轨。
- 通过 HTTP 接口完成上传、包装配置、导出与文件下载。
- 对历史规则演示执行案例回归与规则锁定检查。

## 项目实践与职责

项目实践包括：

- 梳理口播剪辑流程和使用场景。
- 定义片段复核、字幕、花字、声音和导出环节的质量要求。
- 规划本地工作台功能和操作顺序。
- 设计工作流、输入输出结构和异常处理方式。
- 通过实际生成文件和自动化测试验证处理结果。

代码实现与测试脚本开发结合 AI 辅助完成。

## 30 秒项目介绍

Xiang Mu 是一个本地口播视频剪辑工作台。我围绕视频导入、静音分析、人工片段复核、字幕编辑和后期包装设计了一套完整流程。它可以将用户确认的片段交给 FFmpeg 实际剪辑，再把字幕、重点花字动画、开头缓推和 BGM/SFX 混合进最终 MP4，同时输出独立 SRT 和质检报告。项目重点是把剪辑判断、包装配置和真实媒体渲染连接起来，让操作过程和最终交付文件保持一致。
