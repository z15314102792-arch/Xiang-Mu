在本机运行完整工作台

完整剪辑功能运行在本机。下载源码并按仓库 README 安装 Python 与 FFmpeg，双击 start-demo.bat 启动工作台。

启动后在浏览器打开 http://127.0.0.1:8990/，即可导入自己的视频素材并完成剪辑与导出。
