## 项目进度查询

「读取项目进度」工作流使用 `project_name=n8n` 进行查询：

- 扫描活动记忆记录：3 条。
- 匹配项目记录：1 条。
- 返回字段：memory_key、memory_type、content、evidence、importance、tags、updatedAt。

不存在的项目名称返回 0 条匹配记录，工作流正常结束。

## 记忆读写

- 「保存记忆」工作流使用 Upsert 保存或更新记录。
- 「读取记忆」工作流按查询条件读回记录。
- Agent Preview 历史执行中，项目进度查询与记忆读取均完成真实工具调用。
