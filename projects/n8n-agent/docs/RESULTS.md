# 运行结果

## 网页搜索与正文读取

Agent 根据任务生成搜索查询，调用 SearXNG 获取网页结果，再将结果 URL 传递给网页读取工具。

- 多轮搜索返回约 42–45 条结果。
- 搜索结果中的 URL 可继续进入正文读取流程。
- 网页读取请求返回 HTTP 200，并获取页面正文供 Agent 分析。

## 文档解析与知识库入库

使用一份 99 行 TXT 文档进行入库验证：

| 环节 | 运行结果 |
|---|---|
| 文档解析 | 成功提取正文 |
| 文本切片 | 生成 2 个文本块 |
| Embedding | 生成 512 维向量 |
| 向量写入 | 写入 Qdrant 的 `agent_knowledge_prod` 集合 |
| 数据读回 | 正文和 metadata 均可读回 |
| 语义检索 | 查询命中相关文本块 |

入库 metadata 包含文件名、来源路径、分类、数据集标记、状态、导入时间和文件属性。

## Agent 知识库检索

Agent 通过原生 Qdrant 知识库工具执行语义检索：

- 使用本地 Embedding 服务生成查询向量。
- 从 `agent_knowledge_prod` 集合检索相关文本块。
- 单次 Agent 检索返回 4 条相关结果。
- Agent 根据检索结果回答文档中的结构化字段。

一次独立语义查询返回的相关结果得分约为 0.6816 和 0.5661。

## 项目进度查询

通过「读取项目进度」工作流查询 `project_name=n8n`：

- 读取活动记忆记录：3 条。
- 匹配项目记录：1 条。
- 返回字段：`memory_key`、`memory_type`、`content`、`evidence`、`importance`、`tags`、`updatedAt`。
- 查询不存在的项目名称时，返回 0 条匹配记录。

## 记忆保存与读取

- 「保存记忆」工作流使用 n8n Data Table Upsert，根据稳定记忆键新增或更新记录。
- 「读取记忆」工作流按输入条件读取结构化记录。
- Agent 可通过工具调用这两条工作流，完成记忆保存和读取。
