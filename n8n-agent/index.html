01 / CAPABILITIES

从单轮问答到多工具协作

把常用能力拆成独立工具，Agent 根据任务组合调用，形成搜索、阅读、检索、记忆与项目管理的连续流程。

WEB RESEARCH

网页搜索与正文阅读

通过 SearXNG 获取搜索结果，再将 URL 交给网页读取工具，提取正文并整合信息。

RAG KNOWLEDGE

个人知识库检索

文档经过解析、切片和 512 维向量化后写入 Qdrant，Agent 使用原生知识库入口进行语义召回。

DOCUMENT INGESTION

多入口文档入库

表单上传与工作流调用共用入库逻辑，统一保存正文、来源、文件类型和分类等元数据。

LONG-TERM MEMORY

长期记忆读写

使用 n8n Data Table 管理结构化记忆，通过稳定键执行新增或更新，并按需读取历史记录。

PROJECT TRACKING

项目进度查询

根据项目名称筛选活动记忆，返回进度正文、证据、重要程度、标签和更新时间。

TOOL ORCHESTRATION

工作流工具调用

Agent 将结构化参数传给独立工作流，接收执行结果并继续完成用户任务。

03 / WORKFLOW LIBRARY

六条可复用工作流

将文档处理、知识写入、记忆管理和项目查询拆分为独立流程，便于单独调用与组合。

01

知识库入库 · 8 节点

表单与子工作流双入口，文档加载、Embedding 和 Qdrant 写入。

02

本地文件读取 · 10 节点

读取文件目录，按 TXT/PDF 分流，提取正文并调用入库子工作流。

03

保存记忆 · 2 节点

使用 Data Table Upsert，根据记忆键新增或更新记录。

04

读取记忆 · 2 节点

按输入条件读取结构化记忆记录。

05

读取项目进度 · 5 节点

标准化查询条件，筛选项目类记忆并返回证据。

06

Agent 工具演示 · 2 节点

接收两个数字，执行计算并返回结构化结果。
